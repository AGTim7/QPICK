# QPICK

Небольшой интернет-магазин на React + TypeScript.


### Главные особенности

* **Имитация запросов к серверу** — загрузка товаров сделана через `setTimeout`, а во время ожидания отображается Skeleton.
* **Анимации** — для появления и удаления товаров из корзины использовал `Motion`.
* **Адаптивность** — интерфейс нормально подстраивается под ПК, планшеты и телефоны.
* **Форма оформления заказа** — `React Hook Form` + `Zod` для управления формой и валидации данных карты.
* **React Context** — состояние корзины доступно из разных компонентов без передачи данных через множество `props`.
* **Кастомные хуки** — основная логика корзины и формы вынесена отдельно от компонентов.
* **React Router** — простая маршрутизация между страницами магазина.
* **sessionStorage** — корзина сохраняется при обновлении страницы в рамках текущей вкладки.
* **Tailwind CSS** — вся стилизация и адаптивность сделаны с помощью Tailwind.

## Стек

React · TypeScript · React Router · Tailwind CSS · React Hook Form · Zod · Motion · Lucide React

## Запуск

```bash
npm install
npm run dev
```
